#  Калькулятор стоимости комбайна + модификации

Этот простая Python-программа, которая помогает посчитать итоговую стоимость сельхозтехники: базового комбайна и выбранных к нему модификаций. 

-----------

- Считает стоимость комбайна + выбранных модификаций
- Учитывает НДС (20%)
- Показывает рекомендации: если ты выбрал жатку - предложит бункер ( ну если смотреть по заданию из ТЗ документа )
- Сохраняет историю расчётов в `history.json`
- Сначала спрашивает данные пользователя (ФИО, компания и т.д.)
  
  P.S это первая версия без использования REST API , следующая версия ForEurasia1 использует уже простенький хтмл сайт и сообствнно REST API

------------

# Что внутри

├── main.py            # Запуск калькулятора

├── data_storage.py    # Работа с файлом истории
├── user.py            # Получение инфы от пользователя
